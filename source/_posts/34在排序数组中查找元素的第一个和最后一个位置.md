网上关于LeetCode的题解非常丰富，但高赞的题解一般设计都很精妙，不太适合初学者学习理解。故记录一版最基础的使用二分查找思想实现时间复杂度 O\(logn\) 的思路，便于初学者学习理解。

## 核心思想：二分查找

本题要求O\(logn\)的时间复杂度在有序数组里查找，故可以考虑二分查找。

简单而言，二分查找的思想就是每次只取一半区间继续进行查找。

新手往往会写出类似二分查找形式的代码，但并没保证每次都只取一半区间继续进行查找（即每次都缩减一半区间的范围），故在最坏情况下会退化成线性遍历 O\(n\)的时间复杂度。

而如何快速简单自查写的是O\(logn\)时间复杂度还是O\(n\)时间复杂度的“伪二分查找”？

可以检查：

1. 算法是否保证每次都会只取一半区间继续进行查找？

2. 在最坏情况下（如考虑极端情况\-数组全为 `target`）是否会退化为线性遍历O\(n\)？

## 思路\&与经典二分查找的区别

本题相当于经典二分查找，其实只是在找到 `mid==target` 的情况后，新增了一个找是否其左右还有其他 `target` 边界的问题。

而对于 `target` 不存在的情况，其实还是和经典二分查找一样的。

因此我们只需要对经典二分查找进行修改，在找到 `mid==target` 后，在`mid`的左右两边子区间（均不包括 `mid` ）继续分别进行二分查找，判断是否还有`target`，即 `target` 区间起终点还能否延申。

## 时间复杂度

二分查找的思想，每次只取一半区间继续进行查找，时间复杂度为 O\(logn\)

本题新增找到`mid==target`后再在`mid`的左右两边子区间分别做二分查找，分别查找是否还有左右`target`边界

而O\(logn\)的时间复杂度相加，最终时间复杂度仍是O\(logn\)

## 算法代码（Python）

```Python
class Solution:
    def searchRange(self, nums: list[int], target: int) -> list[int]:

        """左闭右闭[left,right]"""
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right) // 2
            # 同经典二分查找算法找不到的情况
            if nums[mid] < target:
                left = mid + 1
            elif nums[mid] > target:
                right = mid - 1
            # 在找到 mid == target 后，新增考虑 mid 左右两边子区间（均不包括 mid ）是否还可延申
            else:
                def search_left(left1: int, right1: int) -> int:
                    """左子区间是否还有 target ?(没有则返回当前 mid )"""
                    l_r = mid # 保证没有则返回当前 mid
                    while left1 <= right1:
                        mid1 = (left1 + right1) // 2
                        if nums[mid1] < target: # 当前 mid1 中值 < target ，
                            left1 = mid1 + 1 # 若还存在 target 只能在 mid 右边子区间（不包括 mid1 ）找
                        elif nums[mid1] > target: # 当前 mid1 中值 > target ，
                            right1 = mid1 - 1 # 若还存在 target 只能在 mid1 左边子区间（不包括 mid1 ）找
                        else:
                            right1 = mid1 - 1
                            l_r = mid1  # 等于时更新（找到新的 target -> 记录区间左起点延申）

                    return l_r

                def search_right(left2: int, right2: int) -> int:
                    """右子区间是否还有 target ?(没有则返回当前 mid )"""
                    r_r = mid # 保证没有则返回当前 mid
                    while left2 <= right2:
                        mid2 = (left2 + right2) // 2
                        if nums[mid2] < target:
                            left2 = mid2 + 1
                        elif nums[mid2] > target:
                            right2 = mid2 - 1
                        else:
                            left2 = mid2 + 1
                            r_r = mid2  # 等于时更新（找到新的 target -> 记录区间右终点延申）

                    return r_r

                return [search_left(left, mid - 1), search_right(mid + 1, right)]

        return [-1, -1]
```
